# ZmeyGorynych - Android приложение с боковой панелью

## Описание

Это Android приложение с реализованной боковой панелью (Navigation Drawer), которая доступна на всех активностях приложения.

## Реализованные функции

### Боковая панель (Navigation Drawer)
- **Доступность**: Боковая панель видна на всех активностях приложения
- **Навигация**: Позволяет переключаться между экранами
- **Дизайн**: Современный Material Design с градиентным заголовком

### Пункты меню
1. **Главная** - главный экран приложения
2. **Работа** - экран с календарем и управлением персоналом
3. **Персонал** - управление сотрудниками предприятия
4. **Настройки** - экран настроек приложения с настройками внешнего вида

### Архитектура
- **BaseActivity**: Базовая активность с реализацией Navigation Drawer
- **MainActivity**: Главная активность (наследуется от BaseActivity)
- **WorkActivity**: Активность с календарем и управлением персоналом (наследуется от BaseActivity)
- **PersonnelActivity**: Активность добавления/редактирования сотрудника (наследуется от BaseActivity)
- **PersonnelListActivity**: Активность списка сотрудников (наследуется от BaseActivity)
- **SettingsActivity**: Активность настроек (наследуется от BaseActivity)

## Как использовать

### Способы открытия боковой панели:

1. **Свайп от левого края** - проведите пальцем от левого края экрана вправо
2. **Кнопка в ActionBar** - нажмите на иконку меню (гамбургер) в верхнем левом углу
3. **Кнопка "Открыть меню"** - нажмите на кнопку "Открыть меню" на любом экране
4. **Программное открытие** - можно программно вызвать `drawerLayout.openDrawer(GravityCompat.START)`

### Навигация:
- Выберите нужный пункт в боковой панели для перехода к соответствующему экрану
- Панель автоматически закроется после выбора пункта

#### Работа с персоналом:
- **"Персонал"** → открывает список сотрудников
- **"Создать"** → добавление нового сотрудника
- **Клик по карточке** → редактирование сотрудника
- **"Загрузить"/"Сохранить"** → импорт/экспорт CSV с разделами для персонала и кодов должностей
- **"Сокращения"** → управление кодами должностей и их расшифровками

#### Формат CSV файла:
```
# Персонал
Фамилия,Имя,Отчество,Должность,Предприятие
Иванов,Иван,Иванович,ПМСГ,ПМС 110

# Коды должностей
Сокращение,Полное_название,Категория
ПМСГ,Главный инженер,ПМС
ПМСЗ,Заместитель начальника,ПМС
```

### Закрытие:
- Свайпните влево
- Нажмите кнопку "Назад"
- Нажмите на иконку меню в ActionBar (если панель открыта)
- Нажмите на область вне панели

## Управление персоналом

### Обзор
Приложение включает полнофункциональную систему управления персоналом предприятия с современным интерфейсом и базой данных.

### Основные возможности

#### Интеллектуальная расшифровка должностей
- **ПМС** (Путевая машинная станция): ПМС → Начальник ПМС [номер]
- **ПМСЗ** (Заместитель): ПМСЗ → Заместитель начальника ПМС [номер]
- **ПМСГ** (Главный инженер): ПМСГ → Главный инженер ПМС [номер]
- **ПД ПМС** (Дорожный мастер): ПД → Дорожный мастер ПМС [номер]
- **ПЧ** (Путевая часть): ПЧ → Начальник ПЧ [номер]
- **Гибкое извлечение номеров** - система автоматически находит номера в поле "Предприятие" независимо от формата

#### Управление кодами должностей
- **Динамическая система** - все коды должностей хранятся в базе данных и могут редактироваться
- **CRUD операции** - создание, просмотр, редактирование и удаление кодов должностей
- **Категоризация** - группировка кодов по категориям (ПМС, ПЧ, etc.)
- **Валидация уникальности** - проверка уникальности сокращений при добавлении/редактировании
- **Ручная сортировка** - порядок отображения соответствует порядку создания
- **Интеграция с CSV** - коды должностей экспортируются/импортируются в отдельных секциях

#### Добавление сотрудников
- **Форма добавления** - удобная форма с полями: Фамилия, Имя, Отчество, Должность, Предприятие
- **Автоматическая расшифровка** - сокращения должностей автоматически преобразуются в полные названия с использованием номера из поля "Предприятие"
- **Валидация данных** - проверка обязательных полей
- **Уведомления** - обратная связь о результате операции
- **Прямой доступ к списку** - из бокового меню "Персонал" сразу открывается список сотрудников

#### Просмотр списка персонала
- **Информативные карточки** - каждая карточка содержит ФИО и автоматически расшифрованную должность
- **Умная расшифровка** - система анализирует сокращения в поле "Должность" и номер в поле "Предприятие" для формирования полного названия
- **Интеллектуальное размещение** - StaggeredGridLayout с 3 колонками для оптимального использования пространства
- **Кликабельные карточки** - нажатие на карточку открывает режим редактирования
- **Кнопки управления** - "Создать", "Загрузить", "Сохранить" и "Сокращения" для управления кодами должностей

#### Интеллектуальная сетка (StaggeredGridLayout)
- **Адаптивное размещение** - карточки автоматически размещаются в оптимальном порядке
- **3 колонки** - максимальная эффективность использования пространства
- **Гибкая компоновка** - карточки могут иметь разную высоту в зависимости от содержимого

#### Импорт/Экспорт данных
- **Загрузка из CSV** - импорт списка сотрудников из CSV файла
- **Сохранение в CSV** - экспорт текущего списка сотрудников
- **Интуитивные названия** - кнопки "Загрузить" и "Сохранить"

### Техническая реализация

#### База данных
- **Room Database** - современная ORM для Android
- **Таблицы**: Personnel (сотрудники), WorkType (виды работ)
- **DAO интерфейсы** - для работы с данными
- **Repository паттерн** - для бизнес-логики

#### Архитектура
- **MVVM** - ViewModel для управления состоянием
- **LiveData/Flow** - реактивное обновление интерфейса
- **RecyclerView** - эффективное отображение списков
- **StaggeredGridLayoutManager** - интеллектуальное размещение карточек

### Функции поиска и фильтрации
- **Поиск по ФИО** - мгновенный поиск среди всех сотрудников
- **Реактивный поиск** - результаты обновляются по мере ввода
- **Сброс поиска** - возможность показать полный список

### Управление видами работ
- **Добавление видов работ** - динамическое расширение списка
- **Привязка к сотрудникам** - выбор вида работы при планировании
